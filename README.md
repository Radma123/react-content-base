### Setup
#### Dev
1. `git clone <repo_url>`
2. `cd frontend`
3. `npm run dev`
#### Prod
1. `git clone <repo_url>`
2. `cp example.env .env` (enter your domain)
3. `docker-compose up -d --build`

### Architecture
- React (Vite)
- Nginx
- Docker
- external APIs
